# Amazon Homepage Clone

A responsive Amazon-inspired homepage built using HTML, CSS, and JavaScript. This project recreates the look and feel of Amazon's landing page and is intended to improve front-end development skills, especially in layout design, responsiveness, and UI styling.

## Features

- Amazon-style header with navigation and search bar
- Hero banner and promotional section
- Product card grid with pricing and discounts
- Deals and shopping highlights
- Responsive layout for desktop, tablet, and mobile screens
- Clean and modern styling using vanilla CSS
- Simple JavaScript-based interactivity

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
Amazon-homepage-clone/

```

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/chiragsharma777/Amazon-homepage-clone.git
```

2. Open the project folder:

```bash
cd Amazon-homepage-clone
```

3. Open `index.html` in your browser, or run a local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
